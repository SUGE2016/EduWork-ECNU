# 外部智能体试用插件

[English](README_EN.md)

面向 EduWork-ECNU 0.4.9 / DSH 0.2.1-rc.3 的可选试用插件。自动发现本机 Codex、Cursor，支持手动添加 ACP，通过 DSH 官方 provider 委派任务，在当前会话头部按需显示外部任务状态；没有外部任务时不显示入口。

## 安装与使用

需要 Node.js 24、可用的 Codex 原生登录，以及主会话使用的模型。校内模型登录不等于 Codex 登录；插件不会复制或转发两者的凭据。

1. 在本目录运行 `npm install --legacy-peer-deps --package-lock=false`，再运行 `npm run build`、`npm test`。DSH peer 包由目标桌面 Host 提供，不能用其他版本的 Host 替代。
2. 在 EduWork 的“插件”页面从本地目录安装本目录，重启应用。如果已经单独启用了官方 Codex bundle，先关闭该 bundle，以免重复注册同名工具。本插件仍使用同一官方实现。
3. 打开“设置 → 外部智能体”，检测连接后选择启用。扫描只检查 PATH 和常见安装目录，不启动程序。Codex 使用 DSH 固定版本运行时与现有本机登录；Cursor 需要 Agent CLI，仅安装编辑器不能连接。
4. 在主聊天说：“请用 subagent_codex 分析以下内容，不读写文件：……”。该版本工具天然异步，无需 `run_in_background` 参数。
5. 点击会话顶部“外部任务”：查看任务标题、provider、状态与耗时。最终结果仍由官方链路交回主聊天。点击外部或按 Escape 关闭面板。

本插件不自动加入学校发行版默认配置，也不改变主模型、工作区或权限设置。卸载通过官方插件管理器完成。

## 契约与边界

- 委派、进程回收与通知全部由 `@deepseek-ai/dsh-subagent-codex@0.2.1-rc.3` 和官方 `dsh-tool-subagent` 完成。`permissionMode: never` 不弹出交互授权，并保留 Codex 原生 sandbox 策略；这不是强制只读模式，也不是文件系统隔离。请使用专用测试工作区。
- 只监听公开的 `subagent/start` / `subagent/end`。终态来自实际生命周期事件，不解析模型的自然语言回答，也不拿父会话是否空闲推断子任务状态。
- 展示使用官方 header slot、locale 和 Session projection。可选的实验性 `appendPluginRecord` 只记录父会话内完整状态快照（ID、provider、时间、终止原因、Host epoch），不记录提示词、输出、密钥。没有此插件的读取方保留并跳过这些记录；这不是新增 DSH 核心事件契约。若上游未来提供正式持久状态投影，应优先替换此试用存储。
- 宿主重启后，未收到终态的旧任务显示“状态未知”，不当成仍在运行或已取消。插件安装前的旧任务也显示未知。fork 的继承日志不计入新父会话状态。
- 本版只提供状态观察，不新增取消接口、任务调度器或控制台。官方子代理列表保留。未知终止原因不会显示成成功。
- Cursor 使用 `agent acp`。其他 ACP 在设置中填写名称、可执行文件绝对路径和 JSON 参数数组，例如 `["acp"]`。保存不会启动；“检测连接”仅执行 ACP initialize，不发任务、不登录、不批准权限。握手成功不表示账号或真实模型已验证。不要在参数中填写密钥，先通过智能体自己的登录入口配置。
- 启用状态与连接配置保存在 DSH storage domain，重启恢复；检测结果仅保留到宿主退出。新连接默认关闭。ACP 权限默认 `reject`，复用官方一次性会话语义；已安装不等于支持 ACP。运行中的任务未结束时拒绝停用。停用后可移除手动条目。
- 跨机器调度、详细工具流、恢复/续接不在本版范围；需要扩展 DSH 接口时先讨论再实现。

## 验证

`npm test` 覆盖被动发现、可执行路径、ACP 握手/超时/错误响应、进程清理以及终态区分、宿主重启、重复事件、fork 隔离、坏记录与敏感字段排除。模型委派、运行到完成的界面变化、主聊天结果回传、刷新与会话切换需在目标桌面原包上另行验收；单元测试不代表真实模型验收通过。
